# ISO New England

> ISO New England Inc. is the independent, nonprofit regional transmission organization (RTO) authorized by the Federal Energy Regulatory Commission to operate the high-voltage power system, administer the wholesale electricity markets, and plan the power system for Connecticut, Rhode Island, Massachusetts, Vermont, New Hampshire and most of Maine. It publishes one documented programmatic contract - the Web Services API v1.1 - a read-only RESTful interface of 489 documented GET path templates across 91 market and operations resources, in XML or JSON. The API requires HTTP Basic authentication over SSL using a free, self-serve ISO Express account; anonymous calls return HTTP 401. The same market and system data is also downloadable anonymously as bulk CSV from ISO Express. ISO New England holds no retail customer relationships, so there is no consumer, usage, billing or Green Button data surface of any kind.

## API

- [ISO New England Web Services API v1.1](https://webservices.iso-ne.com/docs/v1.1/): Base path https://webservices.iso-ne.com/api/v1.1. Read-only energy and market data - five-minute and hourly LMPs, day-ahead and real-time demand, generation fuel mix, system load, external interchange and flows, constraints, operating reserve and reserve prices, regulation clearing prices, Forward Capacity Market auction and reconfiguration results, FTR auction clearing prices, NCPC, outages, seven-day and wind forecasts, load forecasts, power system status, demand response dispatch and price-response events, locations, and hourly-bid participant resources.
- Authentication: HTTP Basic over SSL. Credentials come from a free ISO Express account; ISO New England states account holders are automatically granted access to the public data feeds.
- Formats: XML and JSON, selected by a .xml/.json extension on the request URL or by an Accept header.
